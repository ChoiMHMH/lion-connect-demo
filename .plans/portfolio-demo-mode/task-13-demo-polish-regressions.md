# T13 - Demo Polish Regressions

> depends on: T12

## 보장할 동작

포트폴리오 데모 모드의 이력서 작성/수정과 역할별 헤더에서 리뷰어가 오해하거나 화면 흔들림을 느낄 수 있는 후속 회귀를 정리한다.

## 선행 테스트 / 선행 검증

- 이력서 프로필 이미지 업로드 후 수정 재진입 시 기존 이미지 표시 경로 확인
- 직군/직무 드롭다운 open 시 body scrollbar 보존 여부 확인
- 반복 입력 섹션의 빈 row 삭제 버튼 노출 조건 확인
- demo role별 헤더 route map 확인

## 작업

- 이력서 수정 진입 시 프로필 이미지 URL 또는 preview 값이 깨지지 않게 한다.
- 직군/직무 드롭다운을 열어도 오른쪽 scrollbar 영역이 사라지지 않게 한다.
- 학력, 경력, 직무스킬, 수상/활동/기타, 언어, 자격증, 링크의 신규 빈 입력 row에도 삭제 버튼을 기본 표시한다.
- 기업 데모 진입 대표 경로를 기업 홈으로 맞춘다.
- 인재 데모 헤더에서 채용 메뉴를 제거한다.
- 관리자 데모 헤더에서 관리자 홈 메뉴를 제거한다.

## 완료 기준

- 프로필 이미지가 수정 화면 재진입 후 alt 텍스트만 보이는 깨진 이미지 상태가 되지 않는다.
- 직군/직무 드롭다운 open/close 시 레이아웃이 좌우로 흔들리지 않는다.
- 반복 입력 섹션의 신규 빈 row도 즉시 삭제할 수 있다.
- 기업 데모 선택 시 기업 홈이 먼저 표시된다.
- 인재/관리자 헤더에서 중복 의미의 메뉴가 사라진다.
