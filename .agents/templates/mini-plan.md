작성 예시:

```md
## 무엇을 / 왜

단일 컴포넌트의 빈 상태 문구를 더 명확하게 바꾼다.

## 현재 상태

현재 문구가 데이터 없음과 로딩 실패를 구분하지 못한다.

## 선택한 해결책

빈 배열일 때만 "등록된 항목이 없습니다"를 보여준다.

## 대안

- 대안: 에러/빈 상태 공통 문구 사용
- 기각 이유: 실패와 빈 상태를 구분하지 못한다.

## 검증

관련 화면에서 빈 목록 상태를 확인한다.
```
